# 受控整理当前工作区

应用迭代页新增“整理当前工作区”，用于把本地未提交的 AutoResearch 应用源码整理成可审阅候选。

流程先扫描固定源码白名单，并逐项标明纳入或排除原因；归档、研究数据、内置 Codex 上游源码、依赖、构建产物、凭据、本地配置、二进制、大文件和符号链接不进入候选。操作者明确勾选文件后，应用在独立 Git worktree 中生成提交，并在无 GitHub 凭据的隔离克隆中安装依赖、运行单元测试和构建。

自动验证通过后，仍需人工审阅差异并批准。应用只推送候选分支并创建 Pull Request，不会自动合并。原工作区文件和 Git 索引保持不变；验证脚本仍会执行候选项目代码，因此这个隔离不是操作系统级安全沙箱。
