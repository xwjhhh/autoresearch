# 课题 Conda 环境

运行 `npm run preview:environment` 可打开独立的交互预览：`http://127.0.0.1:5178/`。预览只使用浏览器内的模拟数据；正式应用已通过 Electron IPC 接入 Conda 服务。

每个课题按固定课题 ID 保存一个共享环境。创建或绑定后，论文复现和自主实验、Agent 命令、后台任务及实验终端都复用该 prefix。创建、绑定、检查、依赖计划确认、环境锁定和变更记录由 `electron/environments/` 实现。

Agent 不能自行创建虚拟环境或修改共享依赖。依赖更新需先解析计划，再由研究者确认；运行中的任务或终端占用环境时，环境变更会被拒绝。

预览中的包版本、磁盘占用、时间和操作结果均为示例，不会创建真实环境或安装依赖。
